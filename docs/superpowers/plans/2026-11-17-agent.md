# XCMate EPG Agent Implementation Plan

**Goal:** Offline überprüfbaren inkrementellen Aggregator bis zum Draft-PR entwickeln.
**Architecture:** SQLite-State, unabhängige Quellen, explizite Kanalzuordnung, konservatives Artwork, atomare Versionen.
**Tech Stack:** Python 3.11+, ausschließlich Standardbibliothek.
**Spec:** docs/superpowers/specs/2026-11-17-agent-design.md

## Global Constraints
0 USD, keine echten Feeds, keine Live-API-Tests, kein Kodi, kein Merge, kein Publish, kein Schedule.

## Review Focus
- Ungültige neue Quelle darf LastGood und Validatoren nicht ersetzen.
- Gleiche IDs unterschiedlicher Quellen dürfen keine impliziten Aliase erzeugen.
- Abbruch zwischen Dateien darf kein inkonsistentes Manifest erzeugen.
- GZIP-Bomben, DTDs und Token in Bildlinks müssen abgelehnt werden.
- Cache-Verlust erfordert vollständigen sicheren Neuaufbau.

## Aufgaben
- [x] A: Tests für SQLite-Neustart, bedingte Requests, Retry und LastGood; dann state.py/fetch.py implementieren.
- [x] B: Tests für Parser, Zeitzonen, Duplikate, Aliase und Prioritäten; dann xmltv.py implementieren.
- [x] C: Tests für konservatives Matching, fehlende Bilder, API-Fehler und Cache; dann artwork.py implementieren.
- [x] D: Tests für deterministisches GZIP, Hash, Manifest und LastGood; dann export.py implementieren.
- [x] E: CLI, synthetische CI, deaktivierten Produktionsentwurf und Betriebsdokumentation ergänzen.
Je Aufgabe zunächst rote Tests, anschließend Implementierung und gesamte unittest-Suite.

## Abschluss der Entwicklungsiteration

34 lokale Tests, Bootstrap-Smoke und synthetische CLI erfolgreich. Separate Review-Funde zu DEFLATE, Bildtypen und Senderreferenz-Laufzeit behoben. Produktionspersistenz, private Mapping-Abnahme, Quellenrechte und Live-Abnahmen bleiben ausdrücklich offen; Häkchen beziehen sich nur auf die oben beschriebene Offline-Entwicklungsiteration.
