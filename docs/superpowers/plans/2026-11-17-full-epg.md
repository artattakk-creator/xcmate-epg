# Full private EPG V2 Implementation Plan

> Agentic execution: use subagent-driven-development / inline execution task by task; independent mapping and artwork reviews required by Issue #6.

**Goal:** Complete private three-source import, conservative device mapping, real artwork evidence and two private export views.
**Architecture:** Bounded Expat records spool into SQLite; stream immutable export generations. Existing APIs and pilot outputs remain intact.
**Tech Stack:** Python standard library, SQLite, Expat, gzip, urllib.
**Spec:** docs/superpowers/specs/2026-11-17-full-epg-design.md; GitHub Issue #6.

## Global Constraints

- Private data under ignored work/ only; directories 0700, files 0600. No real source addresses/content/IDs in Git or public CI.
- No merge, Pages, public payload, daily job, paid API or Kodi modification. Preserve old exports/caches/47 tests.
- Source-complete and device-confirmed coverage are different; no guessed mappings/artwork, no false FULL status.
- Runtime TMDB credentials only when explicitly configured; no secret copying from GitHub.

## Review Focus

- Late/unknown channel references, invalid durations and overlap conflicts must be counted without dropping unrelated programmes.
- Source-generation rollback and exporter crash must retain prior committed state.
- Same display name and HD/SD similarity never authorize provider mapping.
- Wrong year, ambiguous media hits, transient HTTP failures and secret-bearing URLs never become verified artwork.
- 100-MB decompression, oversized records, entities and multi-source concurrency must remain bounded.
